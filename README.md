# RE/MAX EFFECT Website

Premium, responsive one-page website starter for RE/MAX EFFECT.

## Files
- `index.html`: page structure and Turkish content
- `style.css`: responsive visual design
- `script.js`: mobile navigation and footer year

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then Save.
4. After deployment, configure the custom domain in Pages settings.

## Before public launch
Replace demo imagery and placeholder contact details with approved RE/MAX EFFECT assets and verified office details. Confirm brand-use permissions and domain DNS settings.
